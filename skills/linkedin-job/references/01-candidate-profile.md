# 지원자 프로필 템플릿 / Candidate profile template

이 파일을 작업 폴더의 `profile.md`로 복사해 채운다. **모든 LinkedIn 문구와 지원서 답변은 이 파일에서만 사실을 가져온다.**
모르는 칸은 `[미입력]`으로 둔다(`precheck.py`가 ERROR로 잡아 제출 전에 반드시 채우게 한다). 해당 없는 항목은 지운다.
`profile.md`는 개인정보라 저장소에 커밋하지 않는다(`.gitignore`에 포함).

한국어와 영어 표기가 다른 항목(직함, 회사명, 학교명)은 `한국어 / English`로 둘 다 적는다. 영어 표기는 회사·학교의 **공식 영문명**을 쓴다.

- **출퇴근 가능 범위 / Commute:** [예: 서울·경기 남부, 1시간 이내]
