# 프로필 최적화 / Profile optimization

목표: 리크루터 검색에 걸리고, 열었을 때 10초 안에 "무엇을 하는 사람인지"가 보이게 한다. 모든 문장은 `profile.md` 근거가 있어야 한다.

## 필드 제한 (templates/limits.json)

| 필드 | 제한 | 확인 방법 |
|------|------|----------|
| Headline | 220자 | 외부 실측 2건 일치 (2026-09) |
| About | 2,600자 | 외부 실측 2건 일치 (2026-09) |
| Experience 설명 (경력 1건당) | 2,000자 | 외부 실측 2건 일치 (2026-09) |

LinkedIn 공식 도움말은 자동 접근이 막혀 직접 확인하지 못했다. 입력창이 다른 제한을 보이면 `templates/limits.json`을 고친다. 제한은 바뀔 수 있으므로 **최종 확인은 실제 입력창**에서 한다.

## 작업 순서
1. `profile.md`와 목표 직함(희망 조건)을 읽는다. 목표 공고가 있으면 2~3개를 받아 공통 키워드를 뽑는다(`04-job-evaluation.md`의 키워드 표).
2. 현재 LinkedIn 프로필 텍스트를 사용자에게 붙여넣어 달라고 한다(로그인 페이지를 대신 열거나 긁어오지 않는다).
3. `templates/profile-draft.md` 형식으로 언어별 초안을 만든다. 현재 문구와 바꾼 문구를 나란히 보여준다.
4. `li_lint.py`와 `precheck.py --profile profile.md --public`로 검사한다. ERROR는 모두 고친다.
5. 독립 검수(`profile-reviewer-li` 에이전트 또는 아래 체크리스트) 후 사용자가 직접 LinkedIn에 붙여넣는다.

## Headline
- 구조: `[목표 직함] | [핵심 도메인·스킬 2~3개] | [차별점 하나]`. 예(가상): `IT Project Manager | SAP SD/MM · GxP/CSV | APAC rollouts across 4 countries`
- 직함은 **리크루터가 검색하는 표준 직함**을 쓴다. 사내 직급(과장, Associate Manager II)보다 직무명이 우선이다. 단, 실제로 맡은 일의 범위를 넘는 직함은 쓰지 않는다.
- "Open to work", "Looking for opportunities"는 헤드라인 자리를 낭비한다. Open to Work 기능을 쓴다.

## About
- 1~2줄: 누구를 위해 어떤 문제를 푸는지. (접히기 전에 보이는 부분)
- 본문: 대표 성과 2~3개, 각각 숫자 하나. 회사·도메인 맥락 한 줄.
- 끝: 지금 찾는 기회(직무·지역·근무 형태)와 연락 경로("DM 주세요" 정도. 연락처는 Contact info 칸).
- 권장 길이: 제한(2,600자)을 다 채울 필요 없다. 보통 1,000~1,800자면 충분하다.

## Experience
- 각 경력: 첫 줄에 역할 범위(팀·국가·시스템), 그 아래 성과 3~5개.
- 성과 문장: `동사 + 무엇을 + 어떻게 + 결과(수치)`. 수치는 프로필에 있는 것만.
- 같은 회사 내 직함 변경은 LinkedIn의 "같은 회사 여러 직책" 형식으로 나누어 승진 흐름이 보이게 한다.
- 공개 불가 정보(고객사, 내부 시스템명)는 일반화한다: "a global medical-device company's APAC affiliates".

## Skills
- 공고 키워드 ∩ 프로필 근거 = 넣을 스킬. 근거 없는 키워드는 넣지 않고, 사용자에게 "근거가 있으면 profile.md에 추가해 달라"고 묻는다.
- 가장 보여주고 싶은 3~5개를 우선 노출한다. 각 스킬을 어떤 경력·자격증에 연결할지 함께 제안한다.

## 그 밖에
- **Open to Work:** 재직 중이면 "Recruiters only" 공개 범위가 일반적으로 더 안전하다. 그래도 현 회사 리크루터에게 보이지 않는다고 장담할 수 없다는 점을 알린다. 선택은 사용자가 한다.
- **Custom URL:** `linkedin.com/in/<이름>` 형태로 정리하도록 권한다.
- **Featured:** 공개 가능한 결과물(발표, 글, GitHub)만.
- **추천서(Recommendations):** 요청 문구 초안은 쓸 수 있지만, 추천인의 이름으로 추천서 본문을 대신 쓰지 않는다.

## 넘기기 전 체크리스트
- [ ] 모든 직함·기간·수치·자격이 `profile.md`와 일치 (한·영 두 버전 모두)
- [ ] `li_lint.py` ERROR 0건, WARN 확인
- [ ] `precheck.py --profile profile.md --public` ERROR 0건, "프로필에 없는 숫자" WARN 0건 또는 근거 확인
- [ ] 헤드라인에 목표 직함 키워드 포함
- [ ] About 첫 1~2줄에 핵심
- [ ] 마크다운 문법, 연락처, 기밀 정보 없음
- [ ] 학위·자격증 상태(수료, 준비 중)를 사실대로 표기
