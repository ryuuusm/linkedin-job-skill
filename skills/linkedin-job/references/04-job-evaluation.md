# LinkedIn 공고 평가 / Job posting evaluation

순서: **공고 확보 → 사기·유령 공고 점검 → 게이트 → 점수 → 키워드 표.** 원본(ai-job-search-kr)의 게이트·점수 체계를 LinkedIn 공고에 맞게 바꿨다.

## 0. 공고 확보
- 사용자가 **공고 본문을 붙여넣거나** 파일로 준다. linkedin.com 페이지를 자동으로 열거나 긁지 않는다(`06-trust-and-policy.md`).
- 회사 공식 채용 페이지에 같은 공고가 있으면, robots.txt가 허용하는 범위에서 WebFetch로 확인할 수 있다. 공식 페이지와 내용이 다르면 공식 페이지를 우선하고 차이를 알린다.
- 본문은 원문 그대로 `applications/<회사>_<직함>/posting.md`에 저장한다. 요약본은 원문으로 치지 않는다.
- 따로 뽑아 둔다: 직함, 회사, 근무지, 근무 형태(On-site/Hybrid/Remote), 고용 형태, 경력 연차, 필수/우대 요건, 언어, 비자 관련 문구, 게시일, 지원 방식(Easy Apply / 회사 사이트). 없으면 "미확인".

## 1. 사기·유령 공고 점검 (하나라도 해당하면 사용자에게 먼저 알림)
| 신호 | 판정 |
|------|------|
| 지원 과정에서 금전, 장비 구매, 주민등록번호·계좌·여권 사본을 요구 | **중단 권고** (사기 의심) |
| 회사 페이지가 없거나 회사 공식 사이트에서 같은 공고를 찾을 수 없음 | FLAG |
| 메신저(텔레그램·왓츠앱)로만 연락하라고 함 | **중단 권고** |
| 연봉이 시장 대비 비현실적으로 높고 업무 설명이 모호함 | FLAG |
| 같은 공고가 수개월째 반복 게시(재게시) | FLAG (유령 공고 가능성. 단정하지 않음) |
지원자 수, "Promoted" 표시 같은 화면 수치는 평가 근거로 쓰지 않는다.

## 2. 게이트 (PASS / FLAG / FAIL)
| 항목 | FAIL | FLAG | PASS |
|------|------|------|------|
| 근무 자격·비자 | 해당 국가 근무 자격이 없고 공고가 "no sponsorship" 명시 | 비자 언급 없음 → 확인 필요 | 근무 자격 있음 또는 스폰서십 명시 |
| 근무지·근무 형태 | 프로필의 불가 조건(이주 불가인데 해외 on-site 필수 등) | 하이브리드 출근 빈도 미기재, 출퇴근 범위 경계 | 범위 안, 또는 원격 가능 |
| 경력 연차 | 요구 대비 크게 부족 (예: 10년 요구에 3년) | 1~2년 부족, 또는 과잉(지나치게 주니어 직무) | 충족 |
| 필수 요건 (자격·학위·도메인) | 법정·필수 자격 없음 | "or equivalent experience" 문구가 있어 판단 여지 있음 | 충족 |
| 언어 | 프로필에 없는 언어가 필수 | 요구 수준이 프로필 표기보다 높음 | 충족 |

- 경력 연차는 **오늘 날짜 기준**, 재직 중 경력은 오늘까지 포함해 계산하고 계산식을 적는다.
- FAIL이 있으면 점수를 매기지 않고 이유와 공고 문장을 인용한다. 사용자가 프로필에 없는 사정을 알 수 있으니 판단을 묻는다.
- 정보가 없으면 FAIL이 아니라 FLAG(미확인).

## 3. 점수 (각 0~100)
| 항목 | 가중치 | 기준 |
|------|-------|------|
| 직무 역량 | 30% | 필수 요건과 주력 역량의 일치도 |
| 경험 일치 | 25% | 직함이 아니라 실제 업무 내용 비교 |
| 조직·문화 | 15% | 회사 공식 자료, 독립 보도, 리뷰의 반복 키워드. 근거 없으면 "미확인" |
| 커리어 방향 | 30% | 희망 직함·장기 목표와의 정렬 |

종합 = 가중 평균. 근거 없는 항목은 기본값을 넣지 않고 빼서 가중치를 재분배한다(원본 규칙). 판정: 75+ 적극 지원, 60~74 지원, 45~59 선택적, 45 미만 비추천. 경계 ±3점이면 경계라고 밝힌다.

## 4. 키워드 표 (프로필·답변 맞춤용)
| 공고 키워드 | 필수/우대 | 프로필 근거 | 반영 위치 (Headline/About/Experience/Skills/답변) |
|------------|----------|------------|---------------------------------------------|
근거가 없는 키워드는 "근거 없음"으로 두고 반영하지 않는다. 이 표의 키워드를 `precheck.py --keywords`에 넘겨 커버리지를 확인한다.

## 결과물
`applications/<회사>_<직함>/evaluation.md`: 공고 요약, 사기 점검, 게이트 표, 점수표, 키워드 표, 판정, 지원 방식 메모. 보여준 뒤 지원 여부를 사용자에게 묻는다.
